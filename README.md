# 📊 Sistema de Gestión y Analítica - Examen Práctico Tema 3

Aplicación web interactiva desarrollada en **Python** con **Streamlit** para la gestión modular de datos, visualización analítica y procesamiento de información.

---

## 🛠️ Tecnologías y Librerías
* **Lenguaje**: Python 3.x
* **Interfaz de Usuario / Framework**: Streamlit
* **Procesamiento de Datos**: Pandas
* **Visualización de Datos**: Matplotlib
* **Persistencia de Datos**: SQLite / Excel
* **Control de Versiones**: Git & GitHub
